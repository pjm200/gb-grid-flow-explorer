About the model

This is a teaching model, not an operational tool. It shows why boundaries constrain, using real boundary lines and capabilities but simplified everything else.

How it works

  • Boundary-cut transport model. The flow across a boundary equals the net injection on one side: generation + storage discharge − charging + imports − demand. Network topology inside each side is ignored. This is not an AC power flow.
  • Whole-day linear programme, solved twice. The "market" pass ignores boundaries (a copper plate). The "constrained" pass adds the boundary limits. The difference between them is the constraint actions, and the extra cost is the constraint cost.
  • Wind and solar can be turned down at a cost that stands for lost subsidy (£60/MWh wind, £30/MWh solar), so the model curtails only when it has to.

Simplifications to keep in mind

  • Boundary capabilities are ETYS 2025 winter-peak values. Summer uses an assumed derate (0.90 by default), and the reverse-direction limit is assumed equal to the forward limit.
  • Prices (fuel, interconnector markets, curtailment) are illustrative, set in config/*.yaml.
  • Weather is synthetic: one pad position gives smooth, seeded variation in wind and cloud across the country.
  • No unit commitment or minimum stable generation, except that nuclear must run at 85% or more.
  • Plant comes from REPD (wind, solar, batteries) and DUKES 5.11 (gas, biomass, nuclear, pumped storage). Which farms count as transmission-connected uses connection-voltage thresholds by area plus DUKES' own HV/LV flag, so a few may be on the wrong side of that line. Offshore landing points come from the spec's list where known, otherwise the nearest coast. Demand is split across 49 hand-made regions (shares estimated); embedded wind and solar are placed where REPD says those farms are.
  • Internal HVDC links (Western Link etc.) do not change boundary totals in a cut model; their animated flow is a display share of the boundary flow.

Trouble running it?

This web version runs Python inside your browser. Some work networks block parts of the download. If it fails, you get a report to save as a .txt file. checks every file the site needs and gives a report you can save as a .txt file. Nothing is sent anywhere.
